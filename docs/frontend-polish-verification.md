# 商家入口与餐点体验改版验证

日期：2026-09-26。

## 已交付

- 商家或运营身份登录后进入工作台；学生保留登录前的有效返回地址。商家登录页独立标识，不显示学生导航。
- 商家首页默认行为在刷新后保持；商品、订单和店铺设置的直接链接及刷新保留对应子页面。学生端预览为明确操作，附返回工作台入口。
- 新增 `/stalls/:id/products/:productId` 餐点详情，含大图、真实说明、价格库存、摊位、取餐位置、备餐时间、营业限制、数量和购物车操作。
- 首页、搜索、菜单图片与名称、餐袋及结算页面均可打开餐点详情；结算可选信息在同账号、同摊位的页面往返间保留在内存，退出或成功下单清除。
- 搜索支持摊位与餐点分组，关键字保留在地址，刷新和前进后退一致；餐点标签保留可见营业筛选。
- 照片品类入口、餐点卡片、大图详情及手机底部操作条统一视觉。空图使用占位，营业状态真实显示。
- 新增 26 张照片，共 35 张独立作品；31 个原始示例餐点映射 29 张不同照片。原有图片、订单快照保留；现有示例图片地址已用安全命令更新。
- 四个用户指定参考站点写入根目录 `DESIGN.md`、`AGENTS.md` 和素材说明。

## 验证结果

- `npm run build`：TypeScript 检查及 Vite 构建通过。
- `npx playwright test --reporter=list --output=test-results-polish-verified`：**32 项一次运行全部通过，52.3 秒**。
- 覆盖身份分流、商家直接链接刷新、跨标签页登录状态变化、账号注册与关注、商品详情、售罄和下架、数量库存上限、登录后购物车保留、结算备注往返、真实自取订单完成、商家商品上传、评价回复、跨设备设置与 CSV 导出。
- 首页、餐点列表、详情、商家六个页面检查 360 / 390 / 768 / 1440 像素宽度，无横向溢出；菜单照片按实际坐标点击验证。
- `manage.py check`：通过。所有 35 张照片能被 Pillow 解码，作品来源互不重复且署名许可完整。
- 示例图片刷新在独立内存数据库验证：预览不写入、保护上传图和非演示记录、全部非图片字段及历史快照不变、重复执行无操作。实际环境更新后再次 dry-run 为 0 处变化。
- 局域网地址 `http://10.53.8.40:5183/api/v1/health` 返回正常。同 Wi-Fi 手机可继续使用现有地址；本轮没有操作真实手机，移动验证来自浏览器视口。

## 调试中已解决及运行说明

完整回归发现首次加载商家子页面时，身份监听抢占初始路由。已等待路由匹配完成再处理后续身份变化，并加入商品、订单、店铺三条直接访问及刷新回归用例。

本机开发终端进程在验证中退出，导致一次早期整套运行中断。已用独立的 Vite Node API 进程恢复原 5183 端口，记录在 `.runtime/processes.json`；随后完整 32 项通过。原终端退出的外部原因尚未确定，未声称长期运行稳定性已验证。失败运行遗留的测试简介和测试电话已定点还原，最终完整运行恢复了测试期间修改的商家信息。

未部署公网，未配置高德地图正式密钥；地图保留已有明确提示与列表替代。示例摄影不代表实际入驻商户实拍。
