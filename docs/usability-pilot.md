# 首轮观察测试任务卡

状态：**待组织真实参与者，尚无实测结论**。建议 5 位商家、8–12 位学生。避免全部参与者都是项目成员；可按不同手机使用熟练度安排。

## 准备

- 选定一个校园及真实可到访的摊位，先核对地址、认摊照片和营业时段。不能让参与者按虚构示例坐标实地找摊。
- 告知参与者目的、测试不考核个人、随时可退出。记录用编号，不记学号、证件、宿舍房号等无关身份资料；截图隐去电话和账户信息。
- 交易演练使用模拟环境与测试联系方式，不发生真实收款或配送。实际到摊观察和模拟交易结果分别记录。
- S5 提前为参与者的测试学生账号准备至少一笔已完成的模拟订单；M5 提前准备一笔未完成的模拟订单。准备过程不计入任务耗时，不以新账号没有历史订单判定复购功能失败。
- 主持人说明任务后先观察，不提前教点击路径；需要帮助时记录卡点和帮助内容，不把协助完成算独立完成。

## 学生任务

| 编号 | 给参与者的任务 | 观察与记录 |
| --- | --- | --- |
| S1 | 你下课想买点吃的，找到现在可以到访的一家摊位，并说清楚在哪里。 | 从打开页面开始计时；目标 30 秒。是否注意到商家确认时间，是否误认已收摊或暂停线上为完全停业。 |
| S2 | 第一次去这家摊位，请依据页面自己找到它。 | 现场是否找到、找错哪里、是否打电话、耗时。仅对真实地点执行；不要用路线点击代替到达。 |
| S3 | 现场没看到摊位，请告诉平台你遇到的问题。 | 是否找到反馈入口、是否被迫登录、能否理解反馈还需核实。 |
| S4 | 关注这家小摊，再回首页看看它今天是否出摊。 | 游客登录后意图是否保留，两次操作内能否找到关注状态。 |
| S5 | 把小摊分享给同学；再试一次最近订单复购。 | 是否知道二维码访问范围、是否理解价格库存变化、是否误以为点击复购已经下单。 |
| S6 | 同一道菜点两份：一份微辣不要葱，另一份不辣；商家晚了十分钟，查看说明。 | 能否分清每份与整单备注；结算和订单内容是否一致；是否把预计时间误认成已经做好。 |
| S7 | 在测试账号保存恢复码，退出后用它设置新密码。 | 能否找到入口、明白只能使用一次，是否误以为忘记保存后还能查询明文。不记录或截图恢复码。 |
| S8 | 每份餐费不超过 15 元，选一道今天可买的餐点，说明通常要等多久。 | 是否理解预算只含餐费；切换搜索类别、查看详情后返回能否继续筛选；是否把预估当保证时间。 |
| S9 | 同一道餐点买两份不同口味，核对后下单；到摊打开取餐卡，并说出还需付多少钱。 | 逐份要求是否清楚；取餐码、付款状态、原地址和联系入口是否容易找到；异常状态不误认可取餐。 |

## 商家任务

| 编号 | 给参与者的任务 | 观察与记录 |
| --- | --- | --- |
| M1 | 自助提交申请；另一组核对团队代录申请并确认。 | 能否分清草稿、提交和审核；缺少资料时知道下一步吗。审批耗时单独记录，不算表单操作时间。 |
| M2 | 添加一道已准备好的餐点，再添加一道今天尚无库存的餐点。 | 基本商品目标 60 秒；能否分清已保存与可购买，是否误以为系统自动准备了库存。 |
| M3 | 确认今天仍在原地并开摊，然后模拟忙不过来、暂停线上新单。 | 目标原位置开摊不超过两次操作；能否分清线上暂停、暂歇与收摊。 |
| M4 | 两道菜各补若干份，在订单进来时查看剩余数量。 | 是否理解填写的是新增份数；网络中断后是否能用原批次确认结果。 |
| M5 | 收摊，但手里还有一份订单没交付。 | 是否知道停止新单不等于旧单结束；能否找到未完成清单。检查声音是否需要主动开启。 |
| M6 | 为一道菜设置免费辣度选项；接下一份两种口味的订单，再调整出餐预估并说明原因。 | 是否知道在哪里查看每份要求，能否理解剩余分钟和预计时刻，网络结果未知时是否误发第二次调整。 |
| M7 | 尝试开启声音和系统提醒，说明锁屏后是否能完全依赖它接单。 | 是否读懂当前环境限制、知道如何试音与回到订单；不能把未收到的通知记为测试成功。 |
| M8 | 某道菜临时缺料，暂停供应；取消一单、补几份后检查是否恢复销售。 | 是否理解暂停独立于份数，只有商家主动恢复才可继续供应；忙时是否能直接找到操作。 |
| M9 | 同学出示取餐码，找到订单并核对两份口味与金额，然后完成模拟收款和核销。 | 查码与收款是否被误认为一步；错误码、重码及取消申请时能否理解下一步。 |
| M10 | 开启最多 5 单备餐，设置本场停止接单时间，然后锁屏再返回。 | 是否理解待付款占位、旧单继续处理、锁屏不停单；是否知道现场排队不在自动计数中。 |

每轮先解决最常见且影响完成的三类问题，再让新的参与者复测。界面喜好与任务完成分别记录，避免只问“好不好看”。

后续有完整观察周期后，再观察关注者回访、同摊位第二次完成订单及核实后的跑空原因。小样本用于发现问题，不据此宣称学生总体满意度、增长率或商业成功。
