# 视觉参考与图片素材要求

用户端和商家端都必须兼顾完整功能与视觉质量。保持暖橙、奶油白、清晰的文字层级和真实食物照片，避免同一张照片反复代表不同菜品。

设计与素材检索时，应参考以下网站，并把适合本项目的布局、配色、摄影构图和动效方式记录在设计说明中：

- [Dribbble](https://dribbble.com/)：工作台、点餐界面和卡片视觉。
- [Pinterest](https://www.pinterest.com/)：食物摄影、夜市氛围与配色整理。
- [GSAP Showcase](https://gsap.com/showcase/)：交互与动效参考；移动端须节制，并支持减少动态效果偏好。
- [Recent Design](https://recent.design/?ref=godly)：近期网站的排版、留白和页面节奏。

这些网站提供灵感；具体图片是否可以下载分发，以原作品授权为准。进入代码仓库的素材须有可追溯原始来源、作者和明确许可。未核实授权的作品只作参考，不能直接复制进页面。

## 当前素材库

`frontend/public/images` 共 35 张独立摄影作品，本轮增加 26 张，来源均为 Wikimedia Commons 的明确许可作品。31 个原始示例商品使用 29 张不同照片，变体仅在同类菜品中少量共用。补齐了鸡翅、玉米、烤茄子、馄饨、红油抄手、柠檬茶、乌龙、酸梅汤、鸡肉饭、卤肉饭、炒饭、豆腐、土豆、糍粑、圆子、芒果糯米饭和西米露等素材。

所有照片都仅为品类示意，不代表虚构摊位的实拍或精确配料。正式入驻后应优先使用商家获授权的实拍。不同配方、配料和份量不能只靠示意图片推断。

图片按原比例缩小，新增图片最大边 1280px，JPEG 渐进式压缩。本轮素材合计约 5.3MB；页面按需加载，不应一次下载全部素材。来源、作者、许可、分发路径、尺寸和大小记录在 [机器可读清单](../frontend/public/images/sources.json)，人类可读署名见 [图片来源](../frontend/public/images/ATTRIBUTION.md)。

## 更新现有演示数据

新建演示数据库会直接使用新图。已存在的演示数据库使用以下命令，只替换最初种入的图片地址：

```powershell
backend\.venv\Scripts\python.exe backend/manage.py refresh_demo_assets --dry-run
backend\.venv\Scripts\python.exe backend/manage.py refresh_demo_assets
```

命令要求 `DEMO_MODE=true` 且非生产环境，只匹配 `vendor` 示例商户、`DEMO-ONLY` 标记、原始示例名称与原始图片地址。商家上传的照片、改名商品和非示例摊位保持原样。价格、库存、账号、订单、历史订单图片快照、营业状态与位置都不会修改。反复执行不会重复修改已经更新的素材。

已在独立内存数据库验证：预览模式零写入、已上传照片不被覆盖、非演示记录不变、所有非图片字段和历史订单快照不变、重复执行无变化。
