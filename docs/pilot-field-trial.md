# 小范围商户试用记录

本文件是待执行的观察方案，没有填入真实试点结果。先验证摊主能独立维护信息、顾客能否找到摊位，再决定下一批功能。建议单一校园周边或片区邀请 5—8 位摊主、30—50 位顾客；这只是探索规模，不能代表整个市场。

## 开始前

- 记录运行地址、代码版本、日期及负责人，确认运行版本包含本轮数据库迁移。测试账号和模拟交易应始终标明模拟。
- 核验可公开展示的信息与照片使用授权；是否开展交易须单独确认准入。未获交易资格的商户只发布位置、营业和菜品信息。实际试点交易模式由运营向当地主管部门或专业人士确认后再开放。
- 交易商户核验经营资格、有效期、地址、运营授权与支付／配送开通条件。浏览器测试不代替真实微信实付退款和实体手机验收。
- 获得参与者同意后再记录操作。用商户代号和任务代号，不记录证件、付款码、手机号、完整取餐码或顾客轨迹；原始录屏另行征得同意、限制访问并约定删除日期。
- 约定问题联系人与停止试用条件：出现错误收款入口、错单、重复扣款或资格拦截失效时停止新交易，保留已有订单查询、取消和售后处置。

## 现场任务

| 对象 | 任务 | 观察与判定 |
| --- | --- | --- |
| 找摊摊主 | 首次发布真实位置并开摊 | 不由队员代点；记录耗时、错误、提示和协助次数 |
| 找摊摊主 | 下一个实际营业日在老地方开摊 | 是否主动回来；地址是否实际确认，不能用计划营业时间代替 |
| 找摊摊主 | 换位置、暂歇、收摊 | 顾客页同步实际状态；记录忙时维护负担 |
| 找摊摊主 | 标记今天有、卖完、暂时不卖 | 不输入精确库存；顾客菜单和发现页与状态一致 |
| 已准入商户 | 下单、接单、出餐、收款、交餐 | 收款与交餐分别核验；取消及资金异常仍可处理 |
| 顾客 | 找附近摊位、认摊、关注并再次寻找 | 记录是否实际找到及证据；点击导航不算到访成功 |

找不到的原因可选：位置过期、地标不清、提前收摊、现场变动、其他或无法核实。记录查看时的确认时间和状态，不保留顾客定位轨迹。一次计划但未实际营业的日期不计入商户回访分母。

## 复盘与成本

记录任务完成数／尝试数、独立完成数／尝试数、实际找到数／已核实寻摊次数、下一营业日主动使用数／有营业机会的商户数。将未知结果单列；不要把缺失数据算作成功。使用耗时中位数和范围，并保留协助时间。

单列服务器、材料、商户维护、客服和核验工时成本；队员劳动按明确单价估算。访谈愿付费、承诺付费、实际付费分别记录。小样本前后变化同时标注天气、时段及样本差异，不能直接宣称因果改善。

每次改版只选择能被具体观察支持的问题：原行为 → 卡点 → 改动 → 下一次任务结果。是否扩大试点由这些记录决定，不能以新增功能数或测试通过数代替。
