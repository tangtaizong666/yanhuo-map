# 本轮界面截图

这些截图来自隔离浏览器测试，使用示例餐点、测试金额与测试取餐码，不是实际经营记录或用户研究照片。沿用项目已有授权素材，没有新增网络图片。

- `student-budget-*`：预算与通常备餐时间；摊位列表不受餐费预算隐藏。
- `checkout-*`：餐点和逐份要求优先，手机保留底部合计提交。
- `pickup-unpaid-390`：原取餐地址、未付金额、电话与凭证。
- `inventory-correction-390`：盘点更正、冲突提示及明确的线上份数含义。
- `capacity-1440`：默认可选的备餐容量和本场截止。
- `kitchen-390-first-screen`、`kitchen-1440`：出餐台优先动作，查码与次级筛选集中展开。

界面宽度与软键盘模拟不代替真实 Android、iOS、微信内浏览器的检查。完整验证结果见 [验收记录](../../kitchen-verification-20260930.md)。
