# 商家摆摊一分钟使用说明

这份说明书专为摊主在手机上单手看单、备餐和快速交餐编写。在商家工作台（`/merchant`）右上角点 **「说明」**，或在底部 **「更多 → 摆摊使用说明」** 中随时可以打开同款图文卡片。

---

## 一、出摊前准备（首次摆摊只需设一次）

1. **登录商家工作台**：用手机浏览器打开网站并登录商家账号，系统会自动进入商家工作台（`/merchant`）。
2. **设置出摊位置与自动接单**：进入底部 **「更多 → 店铺与营业」**：
   - 在 **出摊位置** 中点击「获取当前定位」或在地图上点选摊位位置（如：哈理工南区正门夜市入口左侧），写清好认的摊位描述并保存。
   - 保持 **「付款后自动接单」** 开启（推荐）：同学在线付完款后订单直接进入「制作中」，夜市高峰双手油烟也不用腾手去点接单！
3. **检查菜品与线上份数**：点底部 **「菜品」**，确认今天要卖的菜品已上架、留给线上预订的份数充足。
4. **开启声音提醒**：点底部 **「更多」**，在「新订单提醒」里点一下 **「开启声音提醒」**（试音成功即可，摆摊期间保持网页在前台）。

---

## 二、每天出摊四步走

### 第 1 步：到了摊位，点「开始营业」
- 在接单台顶部点 **「开始营业」**（或位置即将到期时点 **「确认仍在这里」**）。
- **防跑空机制**：如果超过 **60 分钟** 没有确认位置，系统会自动暂停接新单，避免学生白跑一趟；您只要顺手点一下确认即可恢复接单。

### 第 2 步：线上先付防跑单，直接看单做餐、点「做好了」
- **全部先付再做**：进到您接单台的每一笔单子都**已经由平台自动核验完成线上付款**，不用担心做好了没人要，也**完全不需要您再手动点“确认收款”**！
- **做好装袋**：核对菜品和忌口备注，做好装袋后点大橙色按钮 **「做好了」**，同学手机订单页会立刻弹出 **4 位数字取餐码** 过来取餐。

### 第 3 步：同学到摊，报 4 位码拿走（忙忘了也有三重兜底）
- **平时顺手一点**：同学报出 4 位取餐码核对无误后，直接点卡片上的 **「已交餐 · 完成」**（也可点「取餐码查单 / 输码核销」精确查单）。
- **忙得顾不上点手机也没关系**：
  1. 同学拿到餐后可以在自己手机上点 **「我已取到餐点」** 直接完结；
  2. 就算双方都忘了点，出餐满 **2 小时** 无退款争议，系统也会**自动完结订单并结算分账**（扣除平台技术服务费后净额记入您的分账流水），绝不卡单！

### 第 4 步：现场太忙或卖完了怎么办？
- **摊前排队太长**：直接点接单台顶部的 **「暂停接单」**。暂停后不会再进新单，手头已付款订单照常出餐交接；忙完点「恢复接单」即可。
- **某道菜卖完了**：点底部 **「菜品」**，在对应菜品上点 **「暂停供应」**；新备好一批食材时，点 **「+5 份 / +10 份」** 即可快速补货。
- **准备收摊**：点「店铺与营业」里的 **「收摊」**，把未交接完的尾单处理完即可安心收工。

## 三、常见问题速查

| 现场情况 | 怎么处理最省事 |
| --- | --- |
| 待取餐单子多，怎么一秒找到同学那袋？ | 点页面上的 **「取餐码查单」**，输入同学报出的 **4 位取餐码**，立刻定位对应订单菜品明细。 |
| 同学临时不想买了怎么办？ | 未进制作前同学取消由系统自动原路退回；**一旦进入制作中**，同学只能发起「取消申请」，您若已经下锅制作可点拒绝取消继续出餐，若尚未下锅可点同意取消并原路全额退款。 |
| 在哪里看每天赚了多少净额？ | 点底部 **「更多 → 经营数据」**，清楚展示总收款、平台技术服务费、您的**商户分账净额**与已结算单量，还能一键导出 CSV 对账单。 |
