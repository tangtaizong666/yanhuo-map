# 可信找摊与商家上手：实施与验证记录

日期：2026-09-29。范围：批准的三个批次——可信找摊、商家上手、再次使用与运营观察。当前仍是校园示例环境，付款及配送保持模拟；没有启用真实扣款。

## 已落地

- 首页缩短宣传区，默认显示位置有效的出摊摊位；没有定位按最近确认排序，定位可用时支持距离排序。线下到访与在线点单分开，关注入口和最多三笔已完成订单复购直接可见。餐点仍有独立详情，复购重新核对价格和库存。
- 详情与地图增加认摊说明、独立现场照片、商家确认时间、预计收摊、地址复制、电话与路线。地图或浏览器能力不足时保留文字操作，不伪造定位成功。
- 游客可提交找摊反馈，保存当时展示的位置快照；重复请求去重，结果未知保留原请求。联系方式和自由说明仅运营可见，单条反馈不会改变营业状态。
- 商家支持自助申请、团队代录后本人确认、补资料与审核进度。审批仅建立隐藏、未核验且禁交易的档案；仅查看权限不能审批。工作台按清单引导资料、位置、餐点和审核准备。
- 商品基本添加只需名称、售价、真实可售份数；照片等选填，零库存明确提示补货后可售。批量补货使用增量、原子事务、操作审计和账号/摊位隔离的幂等批次；断网刷新后可以继续确认原批次。
- 开摊、位置确认与未完成订单置于数据图表之前。独立暂停线上新单，不改变线下营业状态；暂歇、收摊不更新时间。提醒临近位置到期，收摊不自动取消旧单。
- 分享和二维码只含公开摊位地址，按公开域名、本机或局域网标识可达范围。来源动作不等于到店或传播成功；回头客统计按真实/模拟模式区分，不声称增长已被验证。
