# 餐袋、复购与双端提醒

日期：2026-09-26。使用独立示例环境联调，未部署公网。

## 本轮交付

- `/cart` 统一餐袋和学生页头数量入口：不同摊位草稿保留在当前浏览器、各自结算；移除或整摊清空可以撤销。
- 餐袋读取真实营业状态、价格与库存。库存不足、售罄、下架、摊位不可用或网络失败时保留草稿并停止结算；新价格必须逐项确认。
- 已完成、已取消、被商家拒绝的订单提供“再来一单”。原生弹窗显示现价与历史价格差异、可补数量和跳过原因；再次核对后只加入餐袋，不直接创建订单。保留其他餐点及其他摊位草稿。
- 学生在首页、搜索、地图、我的和餐袋收到进行中订单提醒，优先显示待取餐。每 15 秒、窗口重新获得焦点或网络恢复时同步；失败明确提示，跨账号旧响应丢弃。
- 商家在各管理页面都能看到待接单数量、最早超时倒计时和取消申请入口。新订单提醒可收起，不因普通刷新重复弹出；声音需点击开启，仅在当前前台页面有效。
- 新增轻量 `GET /api/v1/orders/active-summary`，仅返回当前用户数量和优先提醒订单，不返回取餐码、联系方式、商品明细和备注；响应不缓存。
- 后台预览由 `scripts/start_frontend.py` 建立独立进程组并断开终端输入，运行版本化 Vite API 入口 `frontend/scripts/serve-dev.mjs`；接入 `scripts/start-dev.ps1`，保留局域网参数和端口占用保护。
- 修复网络与身份边界：餐袋请求最多等待 10 秒并开放重试；离页取消等待；账号切换后旧结算成功或变价响应不会清空新账号草稿/幂等记录或跳转；切换摊位后旧请求不能抹掉当前摊位同步错误。

## 运行范围

当前仍是开发示例环境。手机与电脑同一可互访 Wi-Fi 时使用启动脚本输出的局域网地址，电脑需保持开机。本轮移动布局验证来自浏览器视口，没有操作真实手机。没有配置高德正式密钥、生产域名或 HTTPS；地图按既有规则提供列表替代。前台轮询和提示音不等于锁屏或后台推送。

此前使用隐藏终端直接启动的前端在本轮中途退出，未留下 JavaScript 异常或退出事件，外部终止原因尚未确定。已切换为独立进程组启动，再完整通过 47 项；这不代表长时间无人值守稳定性已经验收。

本地 SQLite 验证通过 37 项后端测试，另有 4 项 PostgreSQL 专用竞争测试在本次运行中明确跳过；不以此替代正式环境并发验收。当前后台启动方式已用于本轮联调，但尚未验证长时间无人值守运行。
