# 烟火地图 ·《一镜穿烟火》（方案一：几何匹配 × 穿屏一镜到底答辩先导片）

面向三创赛路演答辩制作的 **48.000 秒、1920×1080、真 60 fps（2880 帧）** 创意视觉宣传片。全片摒弃传统静态截图翻页（零 PPT 感）与喧闹踩点套路，采用 **几何图形匹配（Shape Match-Cut）+ 3D 穿屏空间穿梭（Zoom-Through Portal）+ 112 BPM 轻爵士律动与逐帧微观拟音（Foley SFX）**，一气呵成展现学生端、商家工作台与 `/ops` 平台合规管理台的三端闭环。

## 复现命令

在仓库根目录执行：

```powershell
python promo/yanhuo-matchcut-20261114/tools/create_audio.py
node promo/yanhuo-matchcut-20261114/tools/render.mjs
python promo/yanhuo-matchcut-20261114/tools/verify.py
```

输出文件：`yanhuo-matchcut-48s-1080p60.mp4`、`poster.jpg`、`contact-sheet.jpg`、`verification.json`。所有实景层均由 AI 原创生成（不含真实人物肖像与第三方商户标识），配乐与交互拟音全部由代码合成，演示界面与业务生产数据库严格隔离。
