# 烟火地图 · 这一口，没白惦记

为三创赛路演制作的 60 秒叙事宣传片。输出规格为 16:9 横屏、1920×1080、30 fps、1800 帧、H.264 / AAC MP4；无旁白，配原创纯音乐与中文烧录字幕。当前版本以 `timeline.json` 为剪辑依据，最终文件验证状态见文末。

## 故事与时间表

这是一段明确标注的虚构广告情境：下课后惦记一碗热面，担心摊位是否还在老地方；看手机查看出摊状态与商家确认的位置，决定出发；随后进入烹饪场景，最后夹起惦记的第一口。开头与后半段使用同一碗面的素材呼应，不把不同摄影者的素材说成一次连续实地记录。

| 时间 | 画面与叙事作用 |
| --- | --- |
| 0–7 秒 | 下课后的树影，接一碗面的食欲闪现，建立“想吃什么” |
| 7–16.5 秒 | 步道与看手机的动作，提出“今天，还在老地方吗？” |
| 16.5–20.5 秒 | 独立 HTML 广告情境界面的静态截图，展示虚构摊位、出摊状态及商家确认的位置 |
| 20.5–29.5 秒 | 手机动作接再次迈步与树影，完成查看后的出发决定 |
| 29.5–47 秒 | 翻炒、火焰与调味动作，逐步兑现食物期待 |
| 47–53 秒 | 回到开头同一碗面的素材，夹起第一口，以“这一口，没白惦记”回应开场 |
| 53–60 秒 | 新的 AI 炒面品牌主视觉轻微推近，品牌与创意情境说明收尾 |

时长分配为 **49 秒 Pexels 授权视频素材、4 秒隔离 HTML 情境 UI、7 秒 AI 片尾**；按 30 fps 分别为 1470、120、210 帧，合计 60 秒、1800 帧。实际素材原生帧率不全相同，合成时统一输出 30 fps。

## 音乐

使用本项目原创的 **108 BPM** 器乐配乐，当前版本为 `narrative-v2-no-voice`。合成电钢琴、拨弦、贝斯、打击乐及柔和持续音随故事变化；没有第三方录音、采样、歌词或旁白。成片只使用 `audio/original-bed.wav`，不混入素材视频原声或此前的语音草稿。

| 时间 | 配乐作用 |
| --- | --- |
| 0–12 秒 | 温暖电钢琴与稀疏拨弦主题，4.4 秒后逐渐带出运动感 |
| 12–20 秒 | 鼓与贝斯退出，悬置和声表达不确定；18.8–20 秒留下呼吸空间 |
| 20–27 秒 | C–E–G 动机及大调落点确认决定，节拍回归 |
| 27–38.111 秒 | 轻律动、贝斯、旋律与打击乐逐步推进 |
| 38.111–48 秒 | 全片最完整的编配，呼应烹饪高潮 |
| 48–53 秒 | 打击乐退后，温暖收束，留给第一口 |
| 53–60 秒 | C6/9 和声、主题回声与持续钢琴，最后 2 秒淡出 |

精确时间、声道与合成参数见 `audio/original-bed.json`；该文件的原始音频指标不等同于最终 MP4 的音频验证结果。

## 素材与事实边界

视频素材依据 [Pexels License](https://www.pexels.com/license/) 使用，作品页、作者、官方下载地址及衍生素材关系记录在 `sources.json`，许可核验日期为 2026-10-12。不单独分发未经修改的素材原片，不表示画面中的人物、地点或商户参加本项目或为本项目背书。Dribbble、Pinterest 与 GSAP 仅为已查阅的视觉方向参考，没有直接搬用其设计作品。

**16.5–20.5 秒的界面是广告情境演示，不是本地应用截图或交互录屏。** `assets/product-scenario.html` 是与业务应用隔离的静态场景，`assets/product-scenario.png` 是其截图。界面根据已有的出摊状态、文字地址、商家位置确认时间功能简化制作，虚构“南门小炒摊”“示例校园南门步道旁”“出摊中”及“商家刚刚确认位置”。全程显示“广告情境演示 · 虚构摊位与位置 · 非实时营业信息”，不展示精确 GPS、导航路线、销量、订单、付款或经营效果承诺。

2026-10-12 制作前只读核查时，本地公开示例接口实际返回 **8 家摊位全部 `status=closed`、`can_order=false`**；正在出摊及可点单筛选均为空。没有为广告改写这些状态，也未更改账号、地址、价格、库存、订单、数据库或前后端业务源码。虚构界面中的“出摊中”不代表当前真实营业信息。

界面内 `assets/noodles-story.jpg` 从 alleksana 的 Pexels 视频 `noodles-4223987.mp4` 提取，与故事里的碗面保持连续；它不是商家实拍菜品，也没有覆盖项目或商家的图片。新的 `assets/brand-scene-noodles-ai.png` 由 OpenAI 内置图像生成编辑旧主视觉：仅替换前景餐碗与食物，将原先的一次性碗及宽面卷换成浅鼠尾草绿陶碗、细炒面和蔬菜，参考上述碗面图；保留傍晚校园、冷蓝天空、暖摊灯、背对镜头的模糊厨师、右侧食物与左侧品牌留白。完整编辑提示记录在 `sources.json`。片尾为 AI 静态图加后期轻微推近，不称实拍动态镜头。

旧 `assets/product-current.png` 与 `assets/brand-scene-ai.png` 保留作历史素材，其中旧主视觉也是本次 AI 编辑的输入；两者均未直接用于当前成片。对应历史素材记录标明 `legacy not in current film`。片尾保留“创意情境 · 非项目实地拍摄 · 界面为演示 · 片尾含 AI 画面”。

## 文件与复现

- `yanhuo-ad-60s-1080p.mp4`：最终输出路径；当前版本是否验证通过，以 `verification.json` 为准。
- `poster.jpg`、`contact-sheet.jpg`：封面与每 4 秒一帧的审片缩略图。
- `timeline.json`：镜头入点、时长、裁切、调色及字幕；`captions.ass` 为烧录排版，`captions.srt` 为可复用文字清单。
- `sources.json`：当前视频与衍生图片的作者、来源和许可，以及明确标记的历史素材。
- `assets/product-scenario.html` / `.png`：隔离广告 UI 源文件与合成输入；修改 HTML 后须重新截图更新 PNG。
- `tools/render.py`：FFmpeg 合成脚本；`tools/create_music.py`：原创音乐合成脚本；`tools/verify.py`：完整解码、实际帧数、颜色和音频验证；`audio/original-bed.json`：音乐版本与分段参数。

在项目根目录运行，需 Python、FFmpeg、FFprobe 与 Microsoft YaHei 字体：

```powershell
python promo/yanhuo-20261012/tools/create_music.py
python promo/yanhuo-20261012/tools/render.py --download
python promo/yanhuo-20261012/tools/verify.py
```

`--download` 下载当前清单中缺失的视频原片到已忽略的 `.runtime/promo-stock/`。中间视频存放于本目录 `work/`，按输入与镜头设置缓存；`--preview` 输出 720p 审片文件。HTML 截图与 AI 图片须先准备好，合成脚本不会自动生成它们。最终视频烧录字幕，无须播放器另行加载 SRT。

## 实际验证

2026-10-12 对本叙事版最终 MP4 重新完成全片视频、音频解码，FFmpeg 无错误。实际结果为 **60.000 秒、1920×1080、30 fps、完整解码 1800 帧**；所有帧为 yuv420p、有限范围 BT.709。单一 AAC 48 kHz 双声道音轨，整片响度 **−17.52 LUFS**，真峰值 **−3.13 dBTP**。文件为 64,227,056 字节，SHA-256 和机器可读结果见 `verification.json`。

本地 Chromium 浏览器已静音从头完整播放到结束：60.000 秒、处理 1800 帧、渲染丢帧 0、无媒体错误。该结果是本机播放验收，不代替真实现场投影或听感验收。另已抽帧检查叙事顺序、4 秒产品演示的状态／地址／说明文字及品牌片尾；核对 6 个在用视频来源均有许可记录，所有镜头时长落在整数帧。

前端、后端业务实现均未修改，未运行前后端应用测试，未部署。远端 CI 没有本版运行记录，不能表述为 CI 通过；也未进行真实路演投影设备验收。
