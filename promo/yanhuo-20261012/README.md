# 烟火地图 · 找到惦记的那一口

为三创赛路演制作的 60 秒品牌宣传片。16:9 横屏，1920×1080，30 fps，精确 1800 帧，H.264 / AAC MP4；无旁白，配原创纯音乐和少量烧录字幕。

## 播放与修改

- `yanhuo-ad-60s-1080p.mp4`：可直接播放或插入路演演示文稿的成片。
- `poster.jpg`：片尾封面。
- `contact-sheet.jpg`：每 4 秒一帧的审片缩略图。
- `timeline.json`：每个镜头的入点、时长、裁切、调色和字幕。
- `captions.ass`：实际烧录的字幕与片尾排版；`captions.srt` 为便于复用的文字清单，片尾辅文与主标题合并为一个字幕组。
- `sources.json`：全部素材作者、作品页、下载地址及许可出处。
- `tools/render.py`：可重复执行的 FFmpeg 合成脚本；`tools/create_music.py`：原创配乐合成源文件。

重新输出需要 Python、FFmpeg 和 FFprobe，以及 Microsoft YaHei 字体：

```powershell
python promo/yanhuo-20261012/tools/render.py --download
```

`--download` 只下载缺失的授权视频原片，保存到已忽略的 `.runtime/promo-stock/`。已生成的中间视频保存在本目录 `work/`，按输入与镜头设置缓存；`--preview` 可生成 720p 审片文件。最终视频已包含字幕，无须播放器另行载入 SRT。

## 创意与结构

以温暖的食物近景、自然光和夜灯建立“下课后，去找一口惦记的味道”的情绪。完整画面为主，直接切镜，只在开头和收尾淡入淡出；不使用功能信息卡。脚步、翻炒、倒饮品和筷子夹起食物提供实际运动，结尾品牌画面作极轻微推近。

| 时间 | 画面与目的 |
| --- | --- |
| 0–14 秒 | 锅中热食开场，接脚步、树影与夜灯，进入出发的情绪 |
| 14–31 秒 | 翻炒、火候、手部动作、调味与饮品，集中呈现食物质感 |
| 31–35 秒 | 实际产品的示例摊位页，“出发前，看一眼” |
| 35–49 秒 | 脚步与食物蒙太奇，配乐进入后半段 |
| 49–60 秒 | 夜灯留白，品牌主视觉和“找到惦记的那一口”收尾 |

音乐为本项目原创的 106 BPM 器乐编配，包含合成电钢琴、拨弦、贝斯和轻打击乐。没有使用第三方录音、采样或人声。成片仅使用该音乐轨，未混入源视频声音。

## 素材与事实边界

本片包含 49 秒经编辑的 Pexels 授权视频素材、4 秒本地项目页面截图、7 秒 AI 生成品牌主视觉。它是宣传创意蒙太奇，不表示素材中的地点、人物或商户实际参加本项目，不构成其背书，也不是连续实地拍摄记录。片尾有简短素材性质说明。

视频素材依据 [Pexels License](https://www.pexels.com/license/) 使用；各作者及作品链接完整记录在 `sources.json`。许可于 2026-10-12 核验；不单独分发未经修改的原片。视觉节奏参考了项目指定的 Dribbble、Pinterest 与 GSAP 来源，仅借鉴方向，未搬用其设计作品。

实际页面截图摄于 2026-10-12 的本地示例环境，保留“校园示例环境”“已收摊”和商家位置确认时间。截图是静态展示，不冒充交互录屏；没有改动项目账号、商品、商家状态、价格、订单或支付数据。截图中的烤冷面图为项目已有 CC0 示例图片，作者与原地址也记录在 `sources.json`。

AI 主视觉为本次使用 OpenAI 内置图像生成制作：前景右侧热食，左侧留白，傍晚校园的蓝色背景与暖色摊灯。它只用于品牌结尾，不替换任何商家上传照片，不称为实景拍摄。

本次只新增宣传片与可编辑工程，不修改业务实现，不新增已上线支付、商户规模、用户规模或运营效果的宣传承诺。旁白草稿未用于成片，也不纳入交付。

## 实际验证

2026-10-12 按用户补充要求重新输出 30 fps / 1800 帧版本，对最终 MP4 完成完整视频、音频解码，无 FFmpeg 错误。确认时长 60.000 秒、1920×1080、30 fps、1800 帧、单一 H.264 视频流和 48 kHz 双声道 AAC 音轨；逐帧颜色参数均为有限范围 BT.709 / yuv420p。整片响度为 -17.74 LUFS，真峰值 -3.12 dBTP。机器可读结果及文件 SHA-256 见 `verification.json`。

本版同时将片尾素材说明提高至 28px，底部安全距离 54px；合成脚本把帧率纳入缓存键，并验证最终输出的实际帧数。不同原始帧率的视频统一采样为 30 fps 输出，不声称素材均为原生 30 fps 摄制。
